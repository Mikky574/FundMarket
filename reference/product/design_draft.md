# 市场分析与组合评估平台：软件设计草案

> 状态：讨论稿。未经确认，不执行数据清理或功能迁移。

## 1. 产品定位

这是一个本地运行的“市场研究 + 模拟组合 + 评估实验”平台，而不是自动实盘交易系统。

它服务三类角色：

| 角色 | 核心目标 | 入口 |
| --- | --- | --- |
| 网站访客 | 查看公开市场与公共 AI 组合展示 | 网站只读看板 |
| 账户用户 | 管理个人模拟账户与个人 AI 沙盒 | 登录后网站 |
| 所有者（QQ 837979619） | 研究、生成公共 AI 草案、确认决策、维护程序、拥有环境的所有权限，可以编辑代码 | QQ/Codex 桥接 |

## 2. 功能域

### A. 市场数据与研究

- 股票、基金净值与基金搜索
- 市场概览、行业量化简报、观察列表
- 新闻采集、来源和可用时间标记
- 手动刷新市场研究与展示估值

刷新只更新可再生研究和展示数据；不结算订单、不改变公共组合决策。

### B. 公共 AI 模拟组合

- 只读组合看板：正式账本日期与展示估值日期必须分开显示
- QQ 中生成带证据的决策草案
- 草案确认、决策记录、买入/卖出/加减仓/清仓、撤销和结算
- 全部账本操作经本地受控 API 与审计链完成

状态机：`草案 → 已确认决策 → 已登记订单 → 已结算`。继续观察是无订单的 `WATCH` 决策。

### C. 用户模拟账户与独立 AI

- 用户账户、模拟持仓、买卖与撤单
- 每个用户一个独立 AI 账本/会话，不与公共 AI 账本混用
- 从用户账户初始化或确认同步独立 AI 沙盒

### D. 历史评估实验室

- 导入历史基金、指数、行业和新闻数据
- 每条数据保存 `available_at`，防止未来数据泄漏
- 按历史日期冻结评估会话
- 保存预测、后续计算方向、收益、回撤等评分
- 评估数据与公共组合账本、缓存完全隔离

## 3. 目标模块边界

```text
app/
  api/                 HTTP 边界：路由、请求模型、认证、权限依赖
    users.py            用户账户、个人交易、独立 AI
    internal.py         QQ/Codex 本地受控能力
    market.py           公开行情、基金与研究只读路由（下一阶段）
  market/               数据提供者、缓存、基金/股票/量化研究
  portfolio/            公共组合展示、决策草案、账本控制、结算
  evaluation/           历史数据、新闻、会话、预测与评分
  users/                用户账户、个人组合、个人 AI 领域服务
  static/               前端页面与静态资源
scripts/                数据采集、定时任务、运维命令
tests/                  与模块一一对应的测试
docs/                   架构、流程、数据契约与运维说明
```

现阶段已抽出 `api/internal.py`、`api/users.py`、`api/dependencies.py` 和 `api/schemas.py`；下一阶段再迁移行情与研究路由，保持现有 URL 兼容。

## 4. QQ/Codex 工作模式

- 普通消息：问答、查询、刷新和生成草案；不得改代码或账本文件。
- `/维护 ...`：仅所有者进入代码维护模式，可修改项目源码、运行测试和重启服务。
- 公共组合写入：无论是否处于维护模式，都必须经决策/订单 API 和审计链。

QQ 端需要增加“草案注册表”：草案生成后保存 `draft_id`；确认时以该 ID 写入；成功回复必须带 `decision_id`，失败回复必须带失败阶段。

## 5. 数据分层与清理策略

| 数据类别 | 位置 | 策略 |
| --- | --- | --- |
| 评估模型历史数据 | `D:\应用数据库\市场分析\evaluation_data` | **永久保留**，只允许导入追加与受控归档 |
| 公共组合账本与审计 | `paper/state.json`、审计记录 | **永久保留**，不直接删除 |
| 用户独立 AI 数据 | `D:\应用数据库\市场分析\user_ai` | 保留；仅由用户删除其会话 |
| 市场情报快照 | `market_intelligence` | 可再生；保留最近 14 天，其余清理 |
| 运行日志 | `runtime-logs`、QQ runtime logs | 可清理；保留最近 30 天 |
| 测试临时目录 | `.pytest-*`、`.pytest_cache` | 可全部清理 |
| 实验输出 | `research_evaluation_lab` | 清理前压缩备份或经所有者确认删除 |

清理前必须输出“目标路径、文件数、大小、保留理由”，并采用可恢复的归档/回收站策略；不得使用宽泛递归删除。
