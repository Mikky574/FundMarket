# 平台架构总览

> 版本：讨论稿 v1。本文只定义边界，不触发功能实现或数据清理。

系统由四个独立功能组成：

```text
┌──────────────┐    研究证据/草案    ┌──────────────┐
│ 3. 量化研究  ├───────────────────→│ 1. QQ AI 控制 │
└──────┬───────┘                    └──────┬───────┘
       │ 历史特征/预测                     │ 受控决策/订单
       ▼                                  ▼
┌──────────────┐                    ┌──────────────┐
│ 4. 历史评估  │                    │ 公共 AI 账本  │
└──────────────┘                    └──────┬───────┘
                                             │ 只读展示
                                      ┌──────▼───────┐
                                      │ 2. 网站与用户 │
                                      └──────────────┘
```

| 功能 | 目标 | 是否可改公共账本 |
| --- | --- | --- |
| [QQ AI 控制台](qq_control.md) | 所有者操作与流程编排 | 仅经受控 API 和确认流程 |
| [网站与用户模拟交易](web_user.md) | 展示、查询、个人模拟账户 | 否 |
| [量化研究框架](quant_research.md) | 生成可解释研究证据 | 否 |
| [历史评估框架](historical_evaluation.md) | 验证研究和预测可信度 | 否 |

公共组合账本、用户账户、评估数据三者必须独立存储。任何一个模块都不可以通过读取或修改另一个模块的文件来绕过边界。

## 当前代码归属

```text
src/
  qq_control/             QQ 桥接能力、公共 AI 草案、组合账本与展示
  web_user/               网站静态资源、账户、个人交易、独立用户 AI
  quant_research/         行情/基金数据、数据提供者、缓存、量化与情报
  historical_evaluation/  历史数据导入、基准、会话、预测与评分
  main.py                 临时应用装配入口（下一阶段再恢复导入）
  config.py               临时配置入口
tools/                     采集、刷新、账本与日常运维脚本
quality/tests/             自动化测试
data/                      本地账本、缓存、日志、实验输出和测试遗留物（不提交）
docs/                      产品、流程和架构说明
```

本次只进行物理归属拆分，未修复 Python 导入和工具路径，因此当前版本不以可运行性为目标。
