# 功能一：QQ AI 控制台

## 定位

QQ 是所有者与公共 AI 组合交互的唯一控制台。它负责识别意图、调用受控本地接口、保存草案与确认上下文、将结果用中文回发；它不是账本实现本身。

## 能力

- 查询：公共组合、决策、订单、市场研究、评估结果。
- 刷新：只刷新市场研究与展示估值。
- 分析：根据量化研究生成有数据截止日期的决策草案。
- 决策：确认草案后记录 `WATCH`、买入、加仓、减仓、卖出或清仓决策。
- 订单：在决策已记录后登记订单、撤销订单、结算已到期订单。
- 维护：所有者使用 `/维护 ...` 修改源码、运行测试、重启服务。

## 草案确认状态机

```text
查询/研究 → DRAFT(draft_id) → 所有者确认 → RECORDED(decision_id)
                                            → ORDERED(order_id) → SETTLED
```

- 每个草案包含：行动、市场观察、理由、反方证据、失效条件、置信度、证据和数据截止时间。
- `WATCH` 决策确认后写入账本，但没有订单。
- 决策和订单均需成功 API 回执；没有回执不得宣称成功。
- 刷新、草案、决策、订单、结算是五个独立动作，不得混用状态或报错。

## 边界

- 不直接修改公共账本文件、审计文件、用户数据库或评估数据。
- 不从旧聊天记忆拼接“最新”行情；涉及当前数据时必须查询本地能力接口。
- 维护模式可修改代码，但公共账本操作仍走 API 与审计链。
