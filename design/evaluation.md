# 功能四：历史评估框架

## 定位

历史评估框架验证量化研究和 AI 决策方法是否可靠。它在历史时点冻结数据，让系统在不知道未来结果的情况下生成预测，再与后续真实数据评分。

## 数据与隔离

- 保留位置：`D:\应用数据库\市场分析\evaluation_data`。
- 数据类型：历史基金/指数/行业价格、带 `available_at` 的新闻、冻结会话、预测和评分。
- 此目录与公共账本、市场缓存、运行日志物理隔离；本轮清理必须保留它。

## 点时（Point-in-Time）原则

1. 每条行情和新闻必须记录最早可用时间 `available_at`。
2. 创建 `as_of` 会话时，只能读取该时点及之前已可用的数据。
3. 预测写入后不能改写；评分仅使用之后真实发生的数据。
4. 不允许用后来修订的净值、新闻或标签污染过去会话。

## 评分维度

- 方向准确率与置信度校准。
- 收益、最大回撤、波动和风险调整收益。
- 分市场状态、行业和持有期的表现。
- 覆盖率、数据新鲜度、缺失率和失败率。

目标不是寻找“永远正确”的策略，而是明确框架在什么市场条件下可信、何时应降级为观察。
